# career-campaign-template

Claude Code를 **취준 전담 컨설턴트**로 세팅하는 템플릿. 페르소나(채용 전문가) + 이식형 메모리 + 작업 폴더 구조를 제공한다.

## 무엇이 되나

- 어느 PC에서든 이 폴더에서 `claude`를 실행하면 **10년차 서류 검토관 페르소나**가 자동 로드된다.
- Claude가 세션마다 `./memory/`의 도씨에(내 프로젝트·경력 기록)를 근거로 자소서 첨삭·기업 리서치·코테 코칭·면접 대비를 수행한다.
- git으로 여러 PC에서 같은 상태를 이어간다 (pull → 작업 → push).

## 시작하기

1. 이 템플릿으로 **본인 소유의 private 레포**를 만든다 (Use this template 또는 clone 후 새 원격에 push).
   ⚠️ 지원서·개인정보가 쌓이게 되므로 **반드시 private**.
2. `CLAUDE.md` 상단의 빈칸(이름, github)을 채운다.
3. Git·Claude Code 설치 후 클론 폴더에서 `claude` 실행.
4. 첫 세션에서 Claude에게 요청: "내 프로젝트 자료(README·발표자료·이력서 초안)를 줄 테니 ./memory/에 도씨에를 만들어줘."
   — 이 도씨에가 이후 모든 첨삭의 근거가 된다. **도씨에 없이 첨삭하면 일반론이 나온다.**
5. 이후 세션 루틴은 Claude가 CLAUDE.md 규칙대로 알아서 수행한다 (시작 pull → 메모리 로드 → 종료 push).

## 구조

```
├── CLAUDE.md        # 페르소나 + 메모리 규칙 (Claude가 자동 로드)
├── memory/          # 정본 메모리 — MEMORY.md 인덱스 + 도씨에들
│   ├── companies/   #   회사별 폴더 — 회사마다 status.md("현재 상태" 페이지) 하나
│   ├── projects/    #   프로젝트·경험 도씨에 (자소서·면접 답변의 근거 원장)
│   ├── rules/       #   작업 원칙 — 실수에서 얻은 교훈을 규칙으로 박제
│   └── MEMORY.md    #   인덱스 + (연대기 로그는 루트에 job-applications-<시즌>.md)
├── 산출물/           # 자소서·이력서·전략 문서 등 산출물
└── 세팅_사용법.md     # 상세 사용법
```

### 메모리 폴더 구조의 의도 (원 사용자의 실전 교훈)

지원하는 회사가 늘면 단일 연대기 파일만으로는 "이 회사 지금 어느 단계지?"를 찾기 어려워진다. 그래서 이원화한다:

- **연대기**(`job-applications-<시즌>.md`): 모든 일의 히스토리를 시간순으로 쌓는 append-only 로그. 지우지 않는다.
- **회사별 status.md**(`companies/<회사>/`): 그 회사의 **현재 상태만** — 트랙 단계 한 줄, 확정 일정([확정]/[예상]/[미확인] 표기), 다음 액션 2~3개, 관련 문서 링크. 세션 시작 때 Claude가 이것부터 읽는다.
- `companies/_example/status.md` 에 형식 예시가 있다 (실사용 시작하면 삭제).

## 잘 쓰는 요령 (원 사용자의 실전 교훈)

- **사실 검증을 습관화**: 커뮤니티 후기·수치는 작성 시점과 원출처를 확인하게 하라. "정확해?"라고 되물으면 페르소나가 검증 모드로 돈다.
- **수치는 도씨에에서만**: 자소서의 모든 숫자는 memory 도씨에에 근거가 있어야 한다. Claude에게 "이 수치 근거 있어?"를 물어라.
- **단계 연결**: 서류 끝나면 코테 전략, 코테 끝나면 면접 카드 — "다음 단계 대비까지"를 요구하라.
- **복기 문화**: 코테 문제를 풀면 결과·코드·막힌 지점을 던지고 복기를 요청하라. 기록이 쌓일수록 코칭이 정밀해진다.
